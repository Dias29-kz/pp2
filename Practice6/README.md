# Practice 6: Python File Handling and Built-in Functions

## Objective
This practice covers Python file handling, directory management, and built-in functions.

## Structure
- `file_handling/`
- `directory_management/`
- `builtin_functions/`

## Topics Covered
- File modes: `r`, `w`, `a`
- Reading files: `read()`, `readline()`, `readlines()`
- Writing and appending files
- Using `with` statement
- File and path operations with `os`, `shutil`, `pathlib`
- Directory management
- Built-in functions: `map()`, `filter()`, `reduce()`, `enumerate()`, `zip()`, `len()`, `sum()`, `min()`, `max()`, `sorted()`

## How to Run
Run each Python file separately.
