Practice 10 – Pygame Projects

This project contains three games created using Pygame:

1. Racer
- Player controls a car on the road
- Enemy cars appear
- Coins appear randomly on the road
- Collected coins are shown in the top right corner
- Score increases over time
- Game over on collision
- Code is commented

2. Snake
- Snake moves inside the playing area
- Game over if snake hits wall or leaves screen
- Food appears randomly (not on snake or walls)
- Score increases when food is eaten
- Level increases every 4 foods
- Speed increases with level
- Score and level are displayed
- Code is commented

3. Paint
- Drawing application
- Tools: brush, rectangle, circle, eraser
- Color selection available
- Brush size control (+ / -)
- Clear screen option
- Code is commented

How to run:
1. Install dependencies:
   python3 -m pip install -r requirements.txt

2. Run programs:
   python3 racer/main.py
   python3 snake/main.py
   python3 paint/main.py
